# mitene-video-converter

みてね（FamilyAlbum）のアップロード制限に合わせて動画を変換するスクリプト。

## みてねのアップロード制限

[公式ヘルプ](https://help.family-album.com/hc/ja/articles/360038720993)（2025/01/15 更新）に基づく制限:

### 動画

| 項目 | 無料プラン | みてねプレミアム |
|------|-----------|----------------|
| 1動画の長さ | **最大2分** | **最大10分** |
| 1ファイルのサイズ | - | **最大5GB**（PCアップローダー ※プレミアム限定） |
| 総容量 | 無制限 | 無制限 |

- iOS の共有機能からのアップロードは **120MB まで**
- 対応フォーマット: MP4, MOV, 3GP, M4V（MTS は PCアップローダーのみ。**HEVC は非対応**）
- 解像度の上限は明記されていない。4K もアップロード可能だが、[みてね側で若干リサイズされる](https://help.family-album.com/hc/ja/articles/4404482216601)

## 動作要件

- Ruby（macOS 標準で利用可能）
- ffmpeg（`brew install ffmpeg`）

## インストール

```sh
brew install ffmpeg
```

## 使い方

```sh
bin/mitene-convert [options] <ファイルまたはディレクトリ...>
```

### オプション

| オプション | デフォルト | 説明 |
|-----------|----------|------|
| `--plan free\|premium\|pro` | `premium` | 対象プラン（時間制限が変わる） |
| `--output DIR` | `./converted` | 出力ディレクトリ |
| `--dry-run` | - | 変換せず実行内容を表示 |

### 使用例

```sh
# 基本（premium プランに合わせて変換）
bin/mitene-convert input.mov

# 無料プラン向け（2分で分割）
bin/mitene-convert --plan free input.mov

# ディレクトリ一括変換
bin/mitene-convert ./videos/

# 内容を確認するだけ（変換しない）
bin/mitene-convert --dry-run ./videos/
```

## 変換の仕様

### 出力フォーマット
- コンテナ: **MP4**（みてね対応フォーマット中で最も互換性が高い）
- 映像コーデック: **H.264** (libx264)
- 音声コーデック: **AAC** (192kbps)
- `+faststart` フラグ付き（ストリーミング再生対応）

### 品質戦略（制限内で最大品質を目指す）

1. **解像度**: 4K (3840×2160、縦動画は 2160×3840) を超える場合はアスペクト比を保ってダウンスケール
2. **長さ**: プランの制限時間を超える場合は複数ファイルに分割（`_part01`, `_part02` ...）
3. **ファイルサイズ**: セグメントごとに目標サイズを自動計算し、最適なエンコードモードを選択

### 品質の自動計算

セグメントごとの目標サイズ = `min(元動画の按分サイズ, 5GB)`

| 状況 | エンコードモード |
|------|---------------|
| 按分サイズが 5GB 以内かつ調整後ビットレートが目標以下 | **CRF 18**（品質優先） |
| 5GB 上限が binding になり高ビットレートソースが超過する場合 | **固定ビットレート**（サイズ保証） |

> CRF 18 は H.264 の高品質設定です。5GB に収まる範囲では原則として CRF 18 が選択されます。  
> 超高ビットレートソース（4K ProRes 等）で 5GB 制限が効いてくる場合のみ、  
> 目標ビットレートに落として確実にサイズ制限内に収めます。

### 入力対応フォーマット

`.mp4` `.mov` `.qt` `.3gp` `.m4v` `.mts` `.hevc` `.avi` `.mkv` `.wmv` `.flv` `.ts` `.m2ts`
